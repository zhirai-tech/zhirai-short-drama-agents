## 这是什么

一套「短剧创作智能体团队」：一个创作总导演（DIRECTOR）+ 5 个专业角色
（编剧 / 画师 / 配音师 / 音乐师 / 剪辑师）。

用户给一个想法，它会按固定流程产出**真实落盘**的项目文件：
故事总纲 → 角色设定 → 分集卡 → 剧本 → 分镜 → 提示词。

当前阶段只产出**文字**：图片 / 视频 / 配音 / 音乐 / 剪辑环节不执行，
也不会假装已经执行。

## 核心知识资产的保护

本包的 prompt、角色技能、调度拓扑以 **AES-256-GCM 双层密文**存放，
源码内**没有密钥字面量**，解密逻辑本身也被加密。详见 [使用说明.md](./使用说明.md)。
